PRD Reviewer
Paste or upload a draft PRD (.txt, .md, .docx) and get an instant review: a readiness score, an 11-point scorecard, vague wording with measurable rewrites, weak requirements, and the questions engineering will likely ask.
No backend, no API key, no cost. Everything runs in the browser, and the PRD is never uploaded anywhere.
How the score works
Each of 11 checks (problem, target user, metrics, scope, testable requirements, edge cases, error states, dependencies and risks, privacy and security, timeline and ownership, rollout and tracking) scores Pass (1), Partial (0.5) or Fail (0). The score is the total out of 100, minus 2 points per vague sentence (capped at 15).
Host it free
GitHub Pages: push `index.html` to a repo, then Settings > Pages > Deploy from branch > main > Save. Vercel or Netlify: import the repo, no settings needed.
Limits
Rule-based checks (keywords and patterns), not AI: it can miss context and sometimes flags wording that is fine. Treat it as a fast first pass. PDFs aren't supported yet.
